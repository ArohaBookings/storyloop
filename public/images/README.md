# StoryLoop site photos

Drop real photo files into THIS folder with these exact names. The site already
references them. Until a file exists, that slot shows a warm branded placeholder,
so nothing looks broken while you gather images.

Each photo is chosen to MATCH the text beside it, the way Storypark does it.

| Filename                | Where it appears            | What it should show                                             |
|-------------------------|-----------------------------|----------------------------------------------------------------|
| hero.jpg                | Landing hero, right side    | An educator on the floor WITH children, warm, candid, real     |
| observing.jpg           | "Capture the moment" block  | Educator watching/kneeling beside a child mid-play             |
| writing.jpg             | "From note to story" block  | A teacher smiling at a desk (the classroom-desk photo)         |
| children-learning.jpg   | "Grounded in what you saw"  | Children engaged in an activity (alphabet cards / blocks)      |
| whanau.jpg              | Family partnership block    | A calm moment that reads as connection / belonging             |
| about-team.jpg          | About page (optional)       | Anything warm and human; falls back gracefully if absent       |

## How to add them
1. Save each image with the filename above (JPG or PNG both fine, keep JPG name).
2. Put it in `public/images/`.
3. Commit. That is all. No code change needed.

## Sizing guidance
- Landscape, at least 1200px wide. The site crops with object-cover, so exact
  ratio does not matter.
- Clear, well-lit, real people. Avoid anything that looks like stock or AI.

The three images pasted in chat map to: hero.jpg (train play), writing.jpg
(teacher at desk), children-learning.jpg (alphabet cards).
